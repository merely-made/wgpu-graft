[The helper](../../../scripts/observe_scry_mac_session.py) uses Python's standard library to call public Cocoa/CoreGraphics/CoreFoundation APIs, avoiding a new compiled helper or installed bridge. At low priority it emits timestamped JSONL samples every three seconds plus query time, capped at 600 samples and 1800 seconds. It starts before the baseline and determines phase solely from the existence of the four fixed log files. The always-run stop step requests termination through its own stop file and checks matching observer PID, stop acknowledgement and sample bound before artifact upload. Observer setup failure preserves the native batteries; missing completion fails the final observer step. It never kills an app or another process.

Output is limited to runner/console numeric UIDs and equality, WindowServer presence from a bounded exact-name `pgrep`, optional session state, exact owned-bundle PID and activation policy/active/hidden state, own-window onscreen/layer/alpha/extent, and frontmost-is-own/loginwindow booleans. Both the configured bundle path and executable path must match before emitting an app or filtering windows by its PID. The emitted executable path uses `$SCRY_MAC_APP` as an alias, with exact match recorded and the configured path hashed. Other apps' names/PIDs, window titles, URLs, usernames, environment values and pixels are omitted. Exceptions emit only their class. No activation or input is added by this helper.

[Apple's session guidance](https://developer.apple.com/library/archive/documentation/MacOSX/Conceptual/BPMultipleUsers/Concepts/FastUserSwitching.html) documents querying user ID, console presence and login completion through `CGSessionCopyCurrentDictionary`. The helper's explicit dictionary-key spellings are optional compatibility lookups; their availability is not guaranteed by current generated headers. `CGSSessionScreenIsLocked` is an optional undocumented dictionary key, not a public lock-state contract. Missing or wrong-type fields stay null, and neither frontmost classification nor UID equality is used to infer unlock state. The native workflow retains narrowly selected SDK header declarations so actual API availability can be checked without dumping headers or session dictionaries.

[Apple's NSRunningApplication documentation](https://developer.apple.com/documentation/appkit/nsrunningapplication) explains that time-varying properties refresh on main-run-loop turns. The helper permits a short passive CoreFoundation run-loop turn per sample. [CGWindowListCopyWindowInfo](https://developer.apple.com/documentation/coregraphics/cgwindowlistcopywindowinfo%28_%3A_%3A%29?language=objc) can return null outside a GUI security session or without a window server. A null or empty observation is not proof that an app or window is absent from every session. Collection remains race-prone, and onscreen metadata is not a pixel result.
